Run & provenance

Continuous curves integrate dr/ds = J/|J| through a frozen GAMERA snapshot, using all 104,206 cell centres in the extracted volume. Linear tetrahedral interpolation and a 0.12 RE RK4 step define the displayed paths. Moving arrows show conventional-current direction, with illustrative speed.

The MHD inner boundary prevents tracing these paths into the ionosphere. Curves stop at 2.2 RE, weak current, the sampled boundary, a near return to the seed, or the length limit. Endpoints are shown when selecting a path. Interpolation does not enforce divergence-free J, so these paths are a visualization rather than proof of exact current closure. Seed groups help explore the current, rather than uniquely classify entire paths. R1-like seeds select outward dusk / inward dawn current at high latitude on the MHD shell; R2-like seeds select the opposite direction at lower latitude. Purple paths start in westward J at 3–8 RE. These use GAMERA J, not a separate reconstruction of the full energetic-particle ring current.

GAMERA current density is in solar-magnetic Cartesian coordinates. REMIX FAC is mapped to the Apex ionosphere; red is outward from the ionosphere and blue is inward. Browser frames are sampled every 15 minutes from the completed hello_earth_24h run.

The driving OMNI record contains a plasma-data gap from 09:44–12:02 UTC and an IMF gap from 09:46–11:59 UTC on 9 August 2016. Kaipy linearly interpolated those intervals.
